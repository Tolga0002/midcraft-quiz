# 🧠 MidCraft Quiz

Begleit-Quiz zum Programmierkurs mit MidCraft Studio: Programmcode erraten,
Programmier-Wissen, Minecraft-Quiz und Minecraft-Experten-Wissen — mit
Bestenliste auf dem eigenen Gerät.

**Spielen:** https://tolga0002.github.io/midcraft-quiz/

- Läuft komplett im Browser, keine Anmeldung, nichts wird gesendet oder gespeichert
  (nur die Bestenliste bleibt lokal im eigenen Browser).
- Funktioniert auch offline: Doppelklick auf `index.html`.
- Kurs-Modus: Am Ende die Punktzahl in den Zoom-Chat tippen — fertig ist das Kurs-Ranking.

## Dateien

```
index.html            App: Oberfläche, Quiz-Logik, Ranking, Basisfragen
fragen-codeprog.js    Zusatzfragen: Code erraten + Programmier-Wissen
fragen-minecraft.js   Zusatzfragen: Minecraft + Experten-Fachwissen
```

Eigener Code für den Kurs, keine fremden Assets.
